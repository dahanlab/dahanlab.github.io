מפת התוכן המלאה של הפרק

שיעור 1 - תאוריה: מחלקות, עצמים ובנאי (45 דק')

המושגים המרכזיים, לפי הסדר שבו הם נלמדים:

  • מחלקה (class) - תבנית שמגדירה אילו תכונות ואילו מתודות יהיו לכל עצם שייבנה ממנה. המחלקה עצמה אינה עצם ואי אפשר "להשתמש" בה ישירות.
  • עצם / אינסטנס (object / instance) - מופע קונקרטי שנבנה לפי תבנית של מחלקה מסוימת. לכל עצם יש בזיכרון ערכים משלו, שונים מכל עצם אחר שנבנה מאותה מחלקה.
  • תכונה (attribute) - משתנה שנמצא "בתוך" עצם ושומר נתון ששייך לו באופן אישי (self.שם_תכונה).
  • מתודה (method) - פעולה שמוגדרת בתוך מחלקה ומתארת מה עצם מאותה מחלקה "יכול לעשות". הפרמטר הראשון בכל מתודה הוא תמיד self.
  • בנאי / __init__ - מתודה מיוחדת שרצה אוטומטית ורק פעם אחת, ברגע בניית עצם חדש, ותפקידה היחיד הוא לקבוע את הערכים הראשוניים של התכונות של אותו עצם.
  • self - הפרמטר הראשון בכל מתודה. פייתון ממלא אותו אוטומטית בהפניה לעצם הספציפי שעליו הופעלה הפעולה - בלי שהתוכנית מעבירה אותו בעצמה. "self" הוא שם מקובל (קונבנציה), לא מילה שמורה בשפה.

ההסבר המכני המלא של self (זו הנקודה הכי חשובה בשיעור הזה):

כשקוראים ל-r1.area(), פייתון מתרגם את זה מאחורי הקלעים ל-Rectangle.area(r1) - כלומר העצם עצמו מוזרק אוטומטית כארגומנט הראשון. זה לא קסם וזה לא אופציונלי:

  • אם מגדירים בנאי בלי self בכלל (למשל def __init__(name, score)), פייתון עדיין ינסה להזריק את העצם כארגומנט הראשון, וכשקוראים ל-Player("Yossi", 0) מתקבלת השגיאה TypeError: __init__() takes 2 positional arguments but 3 were given - כי שלושה ערכים (העצם + שני הארגומנטים שנשלחו) מנסים להיכנס לשני פרמטרים בלבד.
  • אם self מוזז ממקומו (למשל def __init__(name, self, score)) - אין שגיאה, אבל הקסם מתהפך: העצם עצמו נקשר לפרמטר הראשון בפועל (name), ו-self מקבל את הערך שנועד ל-name. זו ההוכחה שהמיקום של self (לא השם שלו) הוא מה שבאמת נאכף מכנית על ידי פייתון.
  • לעומת זאת, סדר ההגדרה של המתודות בתוך גוף המחלקה לא משנה מכנית בכלל - __init__ יכולה להיות ראשונה או אחרונה בקוד, וזה לא משפיע על איך התוכנית רצה. זה ניגוד מכוון שחשוב להדגיש: מיקום של self בתוך רשימת הפרמטרים = מחייב מכנית; סדר המתודות בקוד = לא משנה בכלל.

כלי עזר שבו השתמשתי בשיעור: pythontutor.com - מציג ויזואלית את הקישור בין המתודה, self, והעצם בזיכרון, כולל הדגמה חיה של מה קורה כש-self חסר או במקום הלא נכון.

שיעור 2 - תרגול מדורג: מחלקות בפעולה (45 דק')

שיעור תרגול טהור, בנוי במתכונת של מעקב מדורג בשלוש רמות קושי על אותו רעיון (מחלקה עם תכונה שמשתנה דרך קריאות למתודות):

  • רמה קלה - מחלקת Counter עם מתודת increase שמעדכנת תכונה מצטברת.
  • רמה בינונית - מחלקת Rectangle עם מתודת area ושימוש בתנאי שמשווה בין שני עצמים.
  • רמה מאתגרת - מחלקת Multiple עם לולאה שקוראת שוב ושוב למתודה שמעדכנת תכונה (self.calls) ומחזירה ערך בו-זמנית.

נקודת התורפה המרכזית של השיעור הזה: ההבדל בין תכונה (self.X) למשתנה מקומי רגיל בתוך מתודה. הדוגמה שבניתי (מחלקת Wallet עם מתודת withdraw) ממחישה איך כתיבת balance = self.balance - amount במקום self.balance = self.balance - amount יוצרת משתנה מקומי חדש שנעלם בסוף המתודה - והעצם בפועל לא משתנה, גם אם נראה כאילו הפעולה "הצליחה".

שיא השיעור: מחלקת Runner עם מתודת is_ahead_of(self, other) שמשווה בין שני עצמים (r1, r2) לפי תכונת distance שמתעדכנת דרך מתודת run. זו הדוגמה המורכבת ביותר בשיעור - שני עצמים "מדברים" זה עם זה דרך מתודה שמקבלת עצם נוסף כפרמטר.

שיעור 3 - שילוב מלא בפורמט הבגרות (45 דק')

השיעור הזה מחבר את כל מה שנלמד לפורמט המדויק של שאלת מחלקות אמיתית בבגרות, שמחולקת לשלושה חלקים (סה"כ כ-20 נקודות):

  • חלק א (מעקב ותיאור מטרה) - בנייה טבלת מעקב לקוד נתון, ולעיתים גם ניסוח משפט אחד שמתאר מה תפקיד מתודה מסוימת.
  • חלק ב (כתיבת מתודה חדשה) - הוספת מתודה חדשה למחלקה קיימת. כאן הנקודה המרכזית היא איפה מוסיפים מתודה (אותה רמת הזחה בתוך גוף המחלקה), ושה-self תמיד ראשון.
  • חלק ג (שימוש בנתונים) - קריאה למתודה החדשה על עצמים קונקרטיים, לרוב כולל לולאה על רשימת עצמים.

דוגמת העוגן של השיעור: מחלקת LibraryBook עם מתודת read קיימת (שמעדכנת current_page), שעליה מוסיפים מתודה חדשה is_finished (שבודקת אם current_page הגיע ל-pages) - ואז משתמשים בה על נתונים קונקרטיים. יש גם תרגיל מלא בסגנון בגרות אמיתי (שאלה מקורית, לא מועתקת משום מבחן אמיתי) שמשלב את שלושת החלקים ברצף, עם חלוקת ניקוד לדוגמה.

נקודות תורפה ושאלות קשות שכדאי להתכונן אליהן

אלה הנקודות שכבר זיהיתי כמועדות לבלבול או לשאלות מאתגרות מתלמידים - אלה בדיוק סוג השאלות שאני רוצה שתאתגר/י אותי איתן:

  1. "למה לא אפשר לקרוא לפרמטר הראשון בשם אחר חוץ מ-self?" - התשובה הנכונה: אפשר טכנית (זו לא מילה שמורה), אבל זה שובר קונבנציה אוניברסלית וגם מבלבל כי הקריאה האוטומטית תמיד מזריקה את העצם למקום הראשון - אז אם קוראים לפרמטר הראשון משהו אחר, הוא עדיין יקבל את העצם, רק עם שם מטעה.
  2. "האם __init__ רצה בכל פעם שניגשים לתכונה?" - לא. היא רצה פעם אחת בלבד, בזמן יצירת העצם.
  3. ההבדל בין self.X (תכונה, נשארת אחרי שהמתודה מסתיימת) לבין X רגיל בתוך מתודה (משתנה מקומי, נעלם בסיום המתודה) - זו המלכודת הכי נפוצה בכתיבת מתודות.
  4. רגישות לאותיות גדולות/קטנות בשמות תכונות (self.Grade לעומת self.grade) - פייתון רואה בהן שתי תכונות שונות לגמרי, וזה גורם ל-AttributeError שנראה "בלתי מוסבר" למי שלא שם לב.
  5. "מה ההבדל בין מחלקה לעצם?" - שאלה בסיסית שתלמידים רבים מתבלבלים בה גם אחרי שהם יודעים "להגדיר" את שני המושגים בנפרד.
  6. סדר ההגדרה של מתודות בתוך מחלקה לא משנה - בניגוד למיקום של self בתוך רשימת הפרמטרים, שכן משנה מכנית.
  7. איפה בדיוק מוסיפים מתודה חדשה למחלקה קיימת (חלק ב בבגרות) - טעות נפוצה היא הזחה לא נכונה שמוציאה את המתודה מחוץ לגוף המחלקה.

דוגמאות קוד מרכזיות (מאומתות בהרצה אמיתית)

# ההדגמה המרכזית של מכניקת self - שיעור 1
class Player:
    def __init__(self, name, score):
        self.name = name
        self.score = score

p1 = Player("Yossi", 0)
# מאחורי הקלעים: Player.__init__(p1, "Yossi", 0)
# self במקום הלא נכון - מה שבאמת קורה
class Player:
    def __init__(name, self, score):
        print("name is actually:", name)   # מקבל את p1 (העצם עצמו)
        print("self is actually:", self)   # מקבל את "Yossi"
        print("score is actually:", score) # מקבל את 0

p1 = Player("Yossi", 0)
# שיא שיעור 2 - שני עצמים "מדברים" זה עם זה
class Runner:
    def __init__(self, name, speed):
        self.name = name
        self.speed = speed
        self.distance = 0

    def run(self, time):
        self.distance = self.distance + self.speed * time

    def is_ahead_of(self, other):
        return self.distance > other.distance
# עוגן שיעור 3 - הוספת מתודה למחלקה קיימת ושימוש בה
class LibraryBook:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages
        self.current_page = 0

    def read(self, pages_read):
        self.current_page = self.current_page + pages_read

    # המתודה החדשה שמתווספת בחלק ב:
    def is_finished(self):
        return self.current_page >= self.pages
